# Examples

This directory contains example scripts and data for using SleepEEGPy.

## Scripts

- `run_preprocessing.py` - Example script for preprocessing EEG data
- `run_analysis.py` - Example script for analyzing preprocessed EEG data

## Data

The `data/sample_data/` directory should contain example EEG recordings. These are typically large files and are not included in the repository by default.

### Supported formats:
- EDF (.edf)
- BrainVision (.vhdr, .vmrk, .eeg)
- FIF (.fif)

See the main README for more information.
