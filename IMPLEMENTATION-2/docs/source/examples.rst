Examples
=========

The `examples` directory contains practical scripts and sample data.

Running Examples
----------------

Example scripts are located in `examples/scripts/`:

**Preprocessing Example:**

.. code-block:: bash

    python examples/scripts/run_preprocessing.py

**Analysis Example:**

.. code-block:: bash

    python examples/scripts/run_analysis.py

Jupyter Notebooks
-----------------

Interactive notebooks demonstrating various features:

1. Data Cleaning
2. ICA Decomposition
3. Dashboard Visualization
4. Event Detection
5. Spectral Analysis
6. Complete Pipeline

Start a Jupyter server and navigate to the `notebooks` directory to explore.
