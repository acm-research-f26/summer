Getting Started
---------------

SleepEEGPy makes it easy to:

- Preprocess EEG signals (filtering, resampling, artifact removal)
- Perform ICA decomposition
- Detect sleep-related events (spindles, slow waves, REMs)
- Analyze spectral properties
- Visualize results interactively

For more information, visit the `GitHub repository <https://github.com/yourusername/sleepeegpy>`_.
